# Task 2 Data

The Task 2 dataset is not currently included in this public repository.

The organizers will provide registered participants with Task 2 JSONL files
through the designated distribution channel after radiologist review is
complete.

Each case will contain:

- a unique case identifier;
- a link to the corresponding MIMIC-CXR report;
- one or more links to the corresponding MIMIC-CXR image;
- an AI-generated causal explanation for verification and correction.

The report and image files themselves are not distributed by the organizers.
Participants must obtain authorized access to MIMIC-CXR and retrieve the
referenced resources in accordance with the applicable license and data-use
requirements.

See [`../SCHEMA.md`](../SCHEMA.md) for the preliminary data format.
