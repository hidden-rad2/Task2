# Task2
Detecting, classifying, and correcting hallucinations in causal explanations for chest X-ray radiology reports.
HIDDEN-RAD2 Task 2 is a causal verification and correction task for chest X-ray radiology. The task evaluates whether AI-generated causal explanations are clinically grounded, whether they contain hallucinated or unsupported claims, and how accurately systems can identify, classify, and correct such errors.
